# Kardan Adam Bahçesi

Küçük çocuklar için kış temalı WebGL oyunu: kar topu yuvarla, kardan adamını kur ve süsle!

**Oyna:** https://halilibrahimeris.github.io/kardan-adam-bahcesi/

## Kontroller
| Tuş | Eylem |
|---|---|
| WASD | Yürü |
| Fare | Etrafa bak |
| Sol tık (basılı) | Kar topu yap |
| E | Topu al / koy |
| V | Kamera değiştir (TPS / FPS) |
| Shift | Koş |
| Esc | Fareyi serbest bırak |

Hata ayıklama paneli için adresin sonuna `?debug=1` ekleyin.
